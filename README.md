# Lower-Limb Exoskeleton for Disabled People

An Arduino-based lower-limb exoskeleton prototype designed to assist sit-to-stand movement through servo-driven knee joints.

## Project Overview

This project focuses on developing a low-cost assistive-technology prototype for people who experience difficulty with sitting and standing movements.

The prototype demonstrates controlled lower-limb movement using an Arduino Uno, servo motors, mechanical linkages and a push-button control system.

## Objectives

- Assist with sit-to-stand movement.
- Demonstrate servo-based knee joint actuation.
- Develop a low-cost and simple assistive-technology prototype.
- Explore embedded programming and hardware interfacing for mobility assistance.

## How It Works

1. Two MG995 servo motors are positioned at the knee joints using mechanical mounting brackets.
2. The Arduino Uno receives input from a push button.
3. Based on the input, the Arduino sends control signals to the servo motors.
4. The servo motors rotate the mechanical linkages to simulate:
   - Sitting movement
   - Standing movement
5. The prototype is powered using Li-ion batteries with regulated power supplied to the Arduino and servo motors.
